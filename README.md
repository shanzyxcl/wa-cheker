# WhatsApp Number Checker

Automated WhatsApp number validation using GitHub Actions.

## Usage

1. Go to **Actions** tab
2. Select **WhatsApp Number Checker**
3. Click **Run workflow**
4. Set parameters (optional):
   - Delay: seconds between checks (default: 3)
   - Batch size: auto-save interval (default: 10)
5. Download results from **Artifacts**

## Results

- `wa_results.json` - Detailed results
- `wa_active_numbers.txt` - Active numbers only
